# FIL_23: `torch` SOLO CPU. Un `pip install -r` a secas resuelve `torch` al
# build CUDA por defecto de PyPI, que arrastra ~4.5 GB de `nvidia-*` +
# `triton` inútiles sin GPU (y que además NO cargan en runtime sin el
# toolkit CUDA del sistema: `OSError: libcudart.so...`). Este índice extra
# publica el wheel `torch==X.Y.Z+cpu`; pip lo prefiere frente al `X.Y.Z` de
# PyPI (el segmento local `+cpu` ordena por encima), así que `pip install -r`
# a secas ya trae el build CPU. Si tu pip es antiguo y aun así instala
# `nvidia-*`, usa el arranque en dos pasos de `modelado/README.md`.
